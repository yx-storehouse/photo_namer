# PhotoNamer 页面设计文档

## 1. 文档目的

这份文档用于给 `photo_namer` 做 UI 重设计时提供完整的页面结构依据。重点不是代码实现细节，而是把当前应用里“有哪些页面、每个页面承担什么任务、页面里有哪些功能区、用户在每个页面会做什么操作”说清楚，方便后续做：

- 信息架构梳理
- 线框图设计
- 视觉风格统一
- 交互重构
- 页面优先级排序

## 2. 当前应用导航结构

### 2.1 一级入口

当前应用的一级入口主要有 4 个：

- 首页拍照管理页 `HomePage`
- 动力抄表页 `MeterRoomsPage`
- 云端同步页 `CloudSyncPage`
- 巡检日历页 `ShiftAwareInspectionCalendarPage`

### 2.2 入口来源

这些入口主要来自两个地方：

- 首页左侧边栏 `Drawer`
- 首页右下角展开式功能按钮 `ExpandableFab`

### 2.3 页面跳转关系

```text
首页 HomePage
├─ 拍照页 CameraPage
├─ 动力抄表页 MeterRoomsPage
│  ├─ 房间详情页 MeterDetailPage
│  │  └─ OCR拍照页 MeterOcrCameraPage
│  └─ 动力超标页 MeterOverloadPage
│     └─ 锁定设备页 MeterLockedDevicesPage
├─ 云端同步页 CloudSyncPage
└─ 巡检日历页 ShiftAwareInspectionCalendarPage

首页设置底部面板
├─ 打包导出 ZIP
├─ 打开云端同步
└─ 打开批量合成页 RawCaptureBatchPage
```

### 2.4 当前不是主入口但需要纳入设计的交互层

这些虽然不是独立路由页，但 UI 权重很高，建议作为“独立设计面板”对待：

- 首页设置底部面板
- 首页新增/编辑预设弹窗
- 首页已完成房间操作面板
- 照片查看全屏弹层
- 云端同步管理员登录弹窗
- 云端同步“选择覆盖范围”弹窗
- 动力抄表房间选择弹窗
- 动力抄表设备设置弹窗

## 3. 设计总原则建议

建议后续 UI 改版时统一遵循以下方向：

- 首页偏“任务调度台”，强调待办、筛选、快速拍照
- 抄表页偏“数据录入台”，强调房间、设备、录入效率
- 超标页偏“模板管理台”，强调模板选择、导出、覆盖、锁定
- 云同步页偏“运维控制台”，强调差异、发布、审核、版本更新
- 巡检日历页偏“个人计划页”，强调今天是否轮到、月度进度、排班参数
- 拍照页偏“沉浸式采集页”，强调取景、状态、水印、快门

建议统一 5 套设计语言：

- 统一卡片圆角、阴影、状态色
- 统一顶部标题区的层级和说明文案
- 统一主操作按钮与次操作按钮样式
- 统一列表页的筛选区、统计区、内容区、操作区结构
- 统一空状态、加载状态、失败状态表现

## 4.1 首页拍照管理页

### 页面定位

这是应用的主工作台，负责管理拍照模板、待办巡检房间、已完成房间、照片打包导出，以及通向其它业务页的入口。

### 页面目标

- 快速找到要拍的房间
- 发起拍照
- 查看已拍结果
- 管理拍照模板
- 导出已拍照片 ZIP
- 打开动力抄表、云同步、巡检日历

### 页面结构

#### A. 顶部导航栏

功能区包含：

- 应用标题 `PhotoNamer`
- 右上角设置按钮

建议重设计时增加：

- 当前工作状态摘要
- 今日巡检进度摘要
- 当前筛选标签提示

#### B. 左侧边栏

功能区包含：

- 动力抄表入口
- 云端同步入口
- 巡检日历入口

建议重设计时可以做成：

- 更清晰的业务分组导航
- 每个入口带副标题和状态徽标
- 巡检/同步/更新提醒角标

#### C. 搜索与筛选区

功能区包含：

- 搜索框：按编号或名称搜索
- 楼层筛选条：按楼层快速过滤

建议重设计时拆成两层：

- 第一层：搜索
- 第二层：楼层、待办/完成、分类模式切换

#### D. 主内容区

当前有两种展示模式：

- 普通分类网格布局
- 融合分类排版布局

核心展示单元是房间卡片 `_RoomCard`，内容包含：

- 房间编号/大字编号
- 房间位置
- 完成状态勾选图标

交互方式：

- 点击未完成卡片：进入拍照
- 点击已完成卡片：弹出已完成操作面板
- 长按卡片：编辑该预设

建议 UI 重设计时明确区分：

- 待拍卡片
- 已拍卡片
- 多张照片房间
- 当前筛选命中态

#### E. 右下角展开式功能按钮

当前动作包括：

- 切到待办
- 切到完成
- 新增预设
- 动力抄表
- 批量合成原图
- 删除已拍照片
- 重置进度

这块现在承担了太多一级操作，建议后续拆分为：

- 主 FAB：新增/拍照类操作
- 页面顶部或底部工具栏：待办/完成切换
- 危险操作收进更多菜单

### 首页关键弹层

#### 1. 新增/编辑预设弹窗

字段包括：

- 编号
- 位置
- 分类
- 保存文件名

可执行操作：

- 新增
- 编辑
- 删除

建议做成更标准的表单抽屉或底部弹层。

#### 2. 已完成房间操作面板

功能包括：

- 查看照片
- 重拍该房间
- 删除该房间照片

建议重设计时加入：

- 照片数量
- 最近拍摄时间
- 是否已打包

#### 3. 照片查看页

当前是全屏图片浏览，支持左右翻页与缩放。

建议重设计时加入：

- 页码
- 文件名
- 删除当前照片
- 分享当前照片

#### 4. 设置底部面板

这是首页最复杂的操作面板之一，包含多个模块：

- ZIP 打包导出
- 云端同步入口
- 保存路径设置
- 权限状态
- 联动设置
- 拍照设置
- 默认水印参数
- 批量合成入口
- 排序方式
- 首页排版模式
- 分类配色主题
- 网格列数

建议后续直接升级成独立“设置页”，而不是一个超长底部面板。

### 首页核心状态

- 空数据状态
- 待办视图
- 已完成视图
- 搜索命中状态
- 楼层筛选状态
- 打包中状态
- 批量合成素材待处理状态

### 首页 UI 改造重点

- 把“任务状态”和“页面设置”分开
- 把“待办/完成切换”从 FAB 挪到页面主结构里
- 强化今日任务感，而不只是模板列表感
- 让卡片更适合高频点击和远距离扫读

## 4.2 拍照页

### 页面定位

拍照页 `CameraPage` 是首页拍照动作进入后的全屏采集页，支持 1 张或 2 张连拍，支持原生实时水印预览、天气自动刷新、地址/天气更新、水印开关、防伪码生成等。

### 页面目标

- 完成单房间拍照
- 实时查看水印效果
- 自动按时段刷新天气
- 自动生成防伪码
- 支持单张/双张采集

### 页面结构

#### A. 顶部透明导航栏

功能区包含：

- 返回按钮
- 页面标题
- 水印开关按钮
- 原生水印控制面板入口

#### B. 相机主取景区

功能区包含：

- 原生相机预览或 Flutter 相机预览
- 取景过渡占位态
- 关闭中占位态
- 水印实时覆盖层

#### C. 实时状态提示区

底部上方有状态胶囊，显示：

- 等待页面切换完成
- 正在打开相机
- 当前拍第几张
- 无水印原图模式
- 原生实时预览 / 实时水印预览

#### D. 主快门区

功能区包含：

- 中部大圆形拍照按钮

### 特殊逻辑

- 进入页面后会按当前时段自动刷新天气
- 水印开启时会自动构建预览数据
- 拍照完成后会回写到首页数据
- 成功导出照片 ZIP 后会自动记录巡检进度

### UI 改造重点

- 更明确区分“相机控制层”和“水印信息层”
- 让状态提示更轻量，不遮挡主体
- 强化拍照成功反馈
- 双张模式下增加更明显的流程提示

## 4.3 批量合成水印页

### 页面定位

`RawCaptureBatchPage` 用于把之前保存的无水印原图批量重新合成带水印照片。

### 页面目标

- 批量处理无水印素材
- 统一覆盖地址/天气/备注/验证文案
- 统一设定时间

### 页面结构

#### A. 页面标题栏

- 标题：批量合成水印

#### B. 待处理概览卡片

展示：

- 当前待处理素材数量
- 批量处理说明

#### C. 4 组参数切换卡片

每组都支持：

- 使用素材库记录值
- 改为统一覆盖值

当前字段包括：

- 地址
- 天气
- 备注块
- 盾牌文案

其中地址卡还支持：

- 读取手机当前定位填入

#### D. 时间设置卡片

支持：

- 使用原始实拍时间
- 使用统一自定义日期时间

#### E. 页面底部主按钮

- 开始批量合成

### UI 改造重点

- 做成明显的“参数向导页”
- 让“沿用原值 / 统一覆盖”切换更清楚
- 把高频操作字段做成分组卡片

## 4.4 动力抄表首页

### 页面定位

`MeterRoomsPage` 是动力抄表业务的入口页，管理已经纳入抄表的房间模板。

### 页面目标

- 浏览抄表房间
- 新增/移除房间
- 导入/导出设备模板
- 导出当前抄表数据
- 打开动力超标模板页

### 页面结构

#### A. 顶部导航栏

- 标题：动力抄表

#### B. 房间内容区

当前为 3 列网格，房间卡片展示：

- 房间名
- 位置

交互：

- 点击：进入房间详情
- 长按：移除房间

#### C. 右下角展开式功能按钮

动作包括：

- 动力超标
- 添加房间
- 导入设备模板
- 导出设备模板
- 导出当前抄表数据
- 清空抄表数据

#### D. 空状态

- 还没有抄表房间
- 引导点击右下角添加

### 辅助弹窗

#### 1. 添加房间弹窗

从首页房间模板里选房间加入抄表。

#### 2. 清空抄表数据确认框

只清数值，不删房间模板。

### UI 改造重点

- 提升“房间模板管理”和“数据录入入口”的区分度
- 强化“当前房间数 / 设备数 / 数据完成度”概览
- 把导入导出类操作从 FAB 中做更清晰分组

## 4.5 抄表房间详情页

### 页面定位

`MeterDetailPage` 是抄表录入主战场，用于编辑某个房间下的设备名称、六个电压电流值，以及触发 OCR 识别。

### 页面目标

- 快速录入设备数值
- 用 OCR 自动识别三相电流
- 管理设备
- 修改房间名

### 页面结构

#### A. 顶部导航栏

功能区包含：

- 页面标题：抄表 - 房间名
- OCR 模式切换菜单
- OCR 调试入口
- 编辑房间名称按钮

OCR 模式分为：

- 自动
- 本地 MLKit
- 在线百度仪表 OCR

#### B. 设备列表区

每个设备是一个卡片，包含：

- 设备名
- OCR 拍照识别按钮
- 设备设置按钮
- 6 个输入框

字段固定为：

- 电压 A/B/C
- 电流 A/B/C

#### C. 右下角展开式功能按钮

动作包括：

- 下一个电流输入框
- 新增 UPS / 进线柜
- OCR 调试结果
- 编辑房间名称

如果当前焦点在电流输入框，会把主按钮替换为“下一个电流输入框”。

### 辅助弹窗

#### 1. 编辑房间名称

- 修改房间名

#### 2. 新增设备

- 输入设备名称

#### 3. 设备设置

- 修改设备名称
- 删除设备

#### 4. OCR 调试结果

展示：

- OCR 全部数字
- 命中的关键行
- 原始 OCR 文本

### UI 改造重点

- 强化“设备头部”和“数值录入区”的分区
- 输入框需要更利于批量录入
- OCR 相关入口建议收敛成一个明显的辅助工具区
- 需要更强的“当前正在录哪个设备、哪个电流相位”的焦点提示

### 页面目标

#### B. 全屏取景区

功能区包含：

- 相机预览
- 半透明遮罩
- 中央绿色识别框
- “识别区域”标签

#### C. 底部说明提示

- 提示把“电流 A/B/C + 单位 A”放入绿色框

#### D. 底部大快门按钮

- 拍照并返回识别

### UI 改造重点

- 继续保持简洁

- 可考虑增加示意图或示例图

## 4.7 动力超标页

### 页面定位

`MeterOverloadPage` 是动力超标模板管理页，用于管理五个时段数据模板、导出模板、随机浮动导出、模板与当前抄表数据互相覆盖。

### 页面目标

- 选择时段模板
- 导出原始模板
- 导出随机浮动后的模板
- 把当前抄表数据写回某个时段
- 把某个时段模板覆盖到当前抄表页
- 设置随机导出排除设备

### 页面结构

#### A. 顶部导航栏

- 标题：动力超标

#### B. 时段导出说明卡

用于解释：

- 已接入五个时段数据
- 先选时段，再导出或回写

#### C. 时段选择列表

五个时段的卡片列表，展示：

- 时段名称
- 房间数
- 设备数
- 录入时间

#### D. 当前选中时段信息卡

展示：

- 当前选中时段
- 房间数量
- 设备数量
- 电流值数量
- 模板源时间

核心操作：

- 将当前抄表数据写入本时段
- 将本时段模板覆盖到当前抄表数据

#### E. 随机浮动导出卡

功能区包含：

- 锁定设备入口
- 已锁定数量提示
- 向下浮动百分比输入
- 向上浮动百分比输入

#### F. 页面底部主操作区

- 导出选中时段数据
- 随机处理后导出

### UI 改造重点

- 让“时段选择”和“操作区”主次更清楚
- 把“模板信息”“当前抄表数据”“导出操作”做三块独立面板
- 随机浮动是高风险操作，建议强化说明和锁定设备提示

## 4.8 锁定设备页

### 页面定位

`MeterLockedDevicesPage` 用于指定某个时段下哪些设备不参与随机浮动导出。

### 页面目标

- 搜索设备
- 批量锁定/解锁
- 查看某房间下已锁设备

### 页面结构

#### A. 顶部导航栏

- 标题：锁定设备 - 时段
- 保存按钮

#### B. 底部固定操作栏

- 取消
- 保存锁定

#### C. 搜索与概览区

包含：

- 搜索框
- 当前时段信息
- 锁定统计
- 筛选条件“仅看已锁定”
- 批量锁定当前筛选
- 批量解锁当前筛选
- 清空本时段锁定

#### D. 房间分组列表

每个房间卡片展示：

- 房间名
- 位置
- 当前显示设备数/总设备数
- 已锁设备数量

房间下方展示设备列表，每个设备可以独立切换锁定状态。

### UI 改造重点

- 当前页更像“筛选式批量管理页”，适合做成主列表 + 右侧筛选工具条
- 房间层和设备层可以强化层级
- 锁定状态应更明显，不要只靠开关

## 4.9 云端同步页

### 页面定位

`CloudSyncPage` 是应用运维中台，负责配置同步、游客提审、差异比对、版本更新。

### 页面目标

- 拉取云端配置到本地
- 发布本地配置到云端
- 游客提交模板更新
- 审核游客提交
- 查看本地与云端差异
- 检查/发布应用更新

### 页面结构

#### A. 顶部导航栏

功能区包含：

- 标题：云端同步
- 右上角管理员身份按钮

管理员按钮状态：

- 未登录：点开管理员验证
- 已登录：显示管理员状态和退出登录

#### B. 同步中心卡

展示：

- 云端是否已发布
- 当前身份：管理员 / 游客

## 4.10 巡检日历页

### 页面定位

当前实际使用的是 `ShiftAwareInspectionCalendarPage`，不是旧版 `InspectionCalendarPage`。这个页面已经包含“个人轮值巡检计划”和“时段记录”两部分。

### 页面目标

- 自动判断今天是否轮到巡检
- 自动判断轮到哪个时段
- 查看月度巡检记录
- 手动补记/全记/清空
- 配置轮班人数和首次轮值日期

### 页面结构

#### A. 顶部导航栏

- 标题：巡检日历
- 今天按钮

#### B. 个人排班计划卡

展示：

- 本月轮到天
- 本月轮到次
- 今日安排

配置区包含：

- 第一个早班日期
- 轮班人数
- 首次轮到巡检日期
- 夜班起始时段选择

说明区包含：

- 班制规则说明
- 班次标签说明
- 未来几天排班预览

#### C. 月历区

展示：

- 月份切换
- 五个时段图例
- 周标题
- 日历网格

每个日期格显示：

- 日期
- 班次角标
- 休息 / 轮休 / x/y 完成数
- 当前轮到的时段徽标
- 额外补记数量

#### D. 选中日期详情卡

展示：

- 完整日期
- 班次
- 休息 / 轮休 / 完成度
- 这一天是否轮到你
- 这一天轮到哪个时段
- 全班应巡时段
- 当前推荐补记时段
- 最后更新时间

可操作：

- 完成我的轮值
- 补记当前推荐时段
- 全部时段记完
- 清空当天

#### E. 时段状态选择区

五个时段以可点击 Chip 形式呈现，可手动勾选完成状态。

### UI 改造重点

- 这是“计划 + 记录”混合页，建议分出更清晰的信息层
- 今日信息建议更突出
- 月历密度高，建议重点优化小格子的文字挤压问题
- 轮休、休息、轮到这三种状态要有非常清晰的视觉区别

## 5. 组件级设计建议

### 5.1 房间卡片

当前房间卡片用于：

- 首页拍照房间
- 动力抄表房间

建议统一组件体系，但保留两种变体：

- 拍照房间卡
- 抄表房间卡

建议可配置字段：

- 主标题
- 副标题
- 状态徽标
- 角标
- 点击动作
- 长按动作

### 5.2 展开式 FAB

当前多页面都用了同一个展开式 FAB。建议后续统一规范：

- 一级主动作不超过 1 个
- 二级动作不超过 4 个
- 危险动作单独视觉标识

### 5.3 统计卡

首页、巡检页、云同步页都存在“小型数据统计卡”的需求，建议统一做：

- 标签
- 数值
- 辅助说明
- 状态色

## 6. 建议的后续 UI 改版优先级

### 第一优先级

- 首页
- 拍照页
- 动力抄表页
- 抄表详情页

这些是最高频使用页面。

### 第二优先级

- 动力超标页
- 锁定设备页
- 巡检日历页

这些是业务效率提升页。

### 第三优先级

- 云端同步页
- 批量合成页
- OCR 拍照页

这些是运维和辅助工具页。

## 7. 备注

- 当前巡检页存在旧版 `InspectionCalendarPage`，但实际主入口已经切到 `ShiftAwareInspectionCalendarPage`，后续 UI 设计建议只围绕新版做。
- 首页设置功能当前过多堆积在一个底部面板里，后续很适合单独拆成“应用设置页”。
- 云同步页功能非常多，最适合拆成多模块式控制台，不建议继续堆成长列表。
